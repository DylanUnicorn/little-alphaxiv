# Little Alphaxiv v0.1.4 — Grounded reading and branching paper chats

v0.1.4 is a large feature release on the v0.1 line. It brings together the
paper-reading and chat improvements merged since v0.1.3 while the product
continues to evolve toward a future v0.2 milestone.

## Highlights

- **Ask AI about a PDF excerpt.** Select text on a page and attach it as a
  removable, page-labelled context card. Add a question in your own words, then
  explicitly send both to the paper conversation without losing an existing
  draft.
- **Explore alternative reasoning paths.** Branch from an assistant answer in a
  paper chat, then navigate the persistent tree from History or the hover quick
  tree. General chats remain deliberately flat.
- **See what the agent is doing.** Tool calls and results are grouped into a
  readable, collapsible activity block with source, query, state, result count,
  and a short preview. Protocol-only messages no longer create blank gaps.
- **Use Responses API providers.** Each OpenAI-compatible provider can now use
  either Chat Completions or Responses API. Existing providers keep their Chat
  Completions setting unless changed.
- **Read PDFs with less friction.** Cold arXiv downloads show live progress,
  text extraction waits until the first page is visible, zoomed pages can be
  panned, and assistant typography and formula rendering are configurable.

The release also prevents duplicate concurrent sends, keeps paper-chat provider
defaults synchronized, fixes selected-text actions at zoomed PDF levels, and
polishes the composer, Markdown blockquotes, formula spacing, and branch-tree
visuals.

## Upgrade

Docker users can update with:

```bash
git pull
cd deploy
docker compose up -d --build
```

Source installations should pull the tag, update frontend and backend
dependencies, and restart both services. Database migrations `0004`–`0007` run
automatically on startup.

Before upgrading, back up `deploy/data/`. Do not remove
`deploy/data/.lax_secret_key`: it protects encrypted provider keys and sessions.
Existing providers, chats, messages, annotations, and settings are retained.

## Current Scope

Little Alphaxiv remains an early-stage v0.1 application. Conversation branching
is currently limited to paper-preview chats, and a few legacy Playwright drivers
still need conversion from localStorage seeding. Docker and source installation
remain the recommended cross-platform options; portable artifacts are listed
under Assets when available.

v0.1.4 是 v0.1 系列的一次大型功能更新，但仍不是 v0.2 里程碑。主要变化包括：

- provider 可选择 Chat Completions 或 Responses API，既有配置保持原默认值；
- arXiv PDF 冷加载提供实时进度，首屏渲染优先，缩放后支持拖拽平移；
- 新增 AI 输出排版与公式显示设置，并修复重复发送、provider 同步和多项交互问题。

升级时数据库迁移会自动执行。请先备份 `deploy/data/`，并且不要删除
