# Little Alphaxiv v0.1.4 Promo Video Implementation Plan

> **For Agent:** REQUIRED SUB-SKILL: Follow this plan task-by-task; use `python-environment` before every Python command and `browser:control-in-app-browser` for live UI inspection.

**Goal:** Produce a polished 55–80 second Chinese promotional video for Little Alphaxiv v0.1.4 that demonstrates the release's headline features with real UI footage.

**Architecture:** A deterministic Playwright capture script seeds a disposable local demo account and records feature-specific WebM clips from the healthy Docker deployment. A standalone Remotion composition turns those clips into a 1920×1080 H.264 video with branded motion graphics, Chinese captions, voiceover, original procedural background music, and a reusable end card.

**Tech Stack:** Python 3 in `Agent_env`, Playwright, edge-tts, React, TypeScript, Remotion, local Docker deployment.
