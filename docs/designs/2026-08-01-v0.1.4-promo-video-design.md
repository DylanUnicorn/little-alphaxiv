# Little Alphaxiv v0.1.4 中文宣传片设计

## 目标与受众

本片面向第一次看到 Little Alphaxiv 的研究者、学生和自托管工具爱好者。目标不是逐项朗读功能表，而是在约 70 秒内让观众理解一条完整价值链：提出研究问题、看到可追溯的搜索过程、打开论文、针对原文追问、从回答中创建分支，最后知道工具可以自托管且支持自己的 OpenAI 兼容 provider。内容以 v0.1.4 release 为事实基线，优先展示 Ask AI、论文聊天分支、透明 Agent 活动、Responses API provider 和 PDF 阅读体验；其它旧功能只作为环境背景出现。

## 创意方向

采用“真实 UI + 程序化镜头包装”的混合路线。真实浏览器操作证明功能可用；Remotion 负责窗口卡片、聚焦缩放、标题、字幕、转场、点击反馈和收尾 CTA。视觉沿用产品的 α 图标、`#7c8cff → #5b6cff` 渐变和深色阅读主题。文案保持直接、短句、少术语。画面必须在静音状态下仍可理解，配音只增加连贯性，不承担唯一信息通道。

## 叙事与分镜

1. **0–5 秒，痛点钩子。** “找论文、读 PDF、问 AI，不该在三个工具之间来回切换。” 背景出现搜索、PDF、聊天三个碎片窗口，随后合并为 Little Alphaxiv。
2. **5–17 秒，发现论文。** 在真实页面中展示问题、论文卡片与可折叠 Agent 活动。字幕：“从问题出发，搜索过程透明可见。”
3. **17–32 秒，基于原文追问。** 进入双栏论文视图，选中 PDF 文本并附加带页码的 Ask AI 上下文卡片。字幕：“选中即问，页码与原文一起进入上下文。”
4. **32–46 秒，分支探索。** 从助手回答选中关键句，创建分支；持久化会话树展开。字幕：“保留主线，放心探索另一条推理路径。”
5. **46–58 秒，阅读与 provider。** 快速展示缩放拖拽、排版设置，以及 provider 的 Responses API 选项。字幕：“阅读体验可调，provider 选择不被锁定。”
6. **58–70 秒，信任与 CTA。** 显示自托管、服务端持久化、API key 加密存储三个要点，收尾为 “Little Alphaxiv v0.1.4 / Read deeply. Think in branches. / GitHub”。

## 声音、交付与验收

中文神经网络配音控制在约 190–230 字，背景音乐使用本地程序生成的轻电子节拍，音量低于配音并在转场处提供轻微脉冲。导出 H.264 MP4、1920×1080、30 fps，并附一张 16:9 封面。浏览器素材用独立演示账号和无敏感信息的样例数据录制。验收包括：完整解码、时长 55–80 秒、无真实 API key/账号信息、字幕无裁切、关键 UI 在普通播放器中可读、静音观看仍能理解主线。
