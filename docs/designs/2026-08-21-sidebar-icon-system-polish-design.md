# 侧栏图标系统统一设计

## 目标

折叠侧栏目前混用了字体字符和线性 SVG：展开使用 `»`，新建聊天使用 `+`，Open Paper 与 Settings 使用 20px、2px 描边 SVG。字体字符受系统字体、基线和字重影响，因此上方两个动作显得偏浅，其中加号尺寸小且视觉中心不稳。完整侧栏底部的 Settings 与 Log out 仍使用 `⚙`、`⎋`，同样存在尺寸、造型和平台差异。此次调整统一图标语言，不改变按钮顺序、尺寸、文字、导航、退出逻辑或主题 token。

## 方案

扩展现有 `SidebarActionIcon`，覆盖 `expand-sidebar`、`collapse-sidebar`、`new-chat`、`open-paper`、`settings`、`log-out` 六个动作。展开与收起采用带左右方向箭头的分栏面板轮廓，既呼应参考图，也比双书名号更准确；新建聊天采用 SVG 十字，固定在 24×24 viewBox 中，并将描边从通用 2px 光学校正为 2.4px，避免只有两根线时显得偏轻。退出使用标准“门 + 向右箭头”，避免当前 `⎋` 被字体渲染成类似回形针的形状。

折叠按钮继续使用 20px 图标和 36×36 容器；展开态标题栏的收起图标缩为 16px；完整侧栏底部按钮使用 18px 图标、居中 flex 布局与 7px 文字间距。所有 SVG 使用 `currentColor`、圆角端点和圆角连接，保留现有 hover、focus 与主题切换。SVG 继续标记为装饰性元素，可访问名称由 Tooltip 或可见文字提供。

## 验收

测试验证六个变体的结构、描边、主题继承和旧字符移除；CSS 契约验证折叠按钮及底部文字按钮均采用 flex 精确居中。随后运行全量 Vitest、TypeScript 和生产构建，并在真实页面中检查亮色、暗色、hover、focus，以及折叠和展开两种侧栏状态。
